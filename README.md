# 📸 Lumina – Social Media Platform

Lumina is a modern **Instagram-inspired social media platform** designed with a clean and interactive user interface. The website delivers a realistic social networking experience through beautifully designed feeds, stories, reels, messaging UI, and responsive layouts, making it an excellent frontend portfolio project.

## ✨ Features

- 📱 Fully responsive design (Mobile, Tablet & Desktop)
- 🏠 Modern home feed
- 📖 Stories section
- 🎬 Reels showcase
- ❤️ Like, comment & share UI
- 👤 User profile page
- 💬 Chat / Messaging interface
- 🔔 Notifications page
- 🔍 Search functionality
- 👥 Explore section
- ⚙️ Settings UI
- 🌙 Clean modern design with smooth animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript

## 🎯 Purpose of the Project

- Practice social media website development
- Improve frontend UI/UX design skills
- Build an Instagram-inspired interface
- Showcase responsive web development
- Create a portfolio-ready social networking project
